Проект работает с коллекцией текстовых документов, прошедших полный цикл предобработки:от сырых 

статей до векторного представления, готового для обучения классификатора и семантического поиска.



Датасет представляет собой корпус коротких текстовых фрагментов (абзацев/лидов новостных и аналитических статей).

Тематика разнородная: бизнес и финансы (Forbes, Reuters), спорт (бейсбол, Олимпиада, футбол), технологии (Microsoft, IBM, Linux),

политика и общество. Каждый фрагмент — это самостоятельный смысловой блок, пригодный для поиска по запросу.
